Personal Mini-Toolkit

Project Description

This project is a Python-based personal mini-toolkit that provides several simple tools through a menu-driven program. The toolkit allows the user to choose a tool, use it, and return to the main menu until they choose to quit.

Tools

The toolkit includes:

1. Calculator - performs basic arithmetic operations.
2. To-Do List - allows users to add, view, and remove tasks.
3. Number Guessing Game - lets users guess a secret number until they find it.
4. Name Formatter - formats a user's full name with proper capitalization.

The program uses Python variables, input/output, conditionals, loops, lists, string methods, error handling, and f-strings.

How to Run

Make sure Python is installed on your computer.

Clone or download this repository.

Open a terminal in the project folder.

Run the program with:

python toolkit.py

Follow the menu instructions displayed by the program.

Reflection

This project helped me bring together the Python concepts I learned during the course. The hardest part was designing the menu so that it could keep running until the user chose to quit. I also had to think carefully about how the different tools would work together in one program. The longest bug was caused by entering invalid input and making sure the program handled it without crashing. Using lists for the to-do tool helped me understand how data can change while a program is running. I also learned that comments and clear output make code easier for another person to understand. With one more week, I would add more useful tools and improve the existing tools with features such as saving data.
